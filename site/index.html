Reorder apps, create folders, hide clutter, and keep favorites close.

Install

One command. Ready to launch.

Install the signed and Apple-notarized release from the official Homebrew tap.

$brew install --cask everettjf/tap/launchdeck

Already installed? Run brew upgrade --cask launchdeck to update.

Prefer a direct download?

Download the notarized ZIP from GitHub Releases and move LaunchDeck to Applications.
