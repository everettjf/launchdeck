# LaunchDeck 1.7 Competitive Task Matrix

These 15 user tasks are executable contracts in `LaunchDeckTests/CompetitiveWorkflowTests.swift` rather than a feature-count checklist.

| # | Task | Reference product | LaunchDeck success condition |
| ---: | --- | --- | --- |
| 1 | Capture multiple Finder selections | LaunchBar Instant Send | Every file becomes a stable object |
| 2 | Capture the current web URL | Spotlight contextual actions | URL is classified without a network request |
| 3 | Offer one action for multiple files | LaunchBar Send To | Batch-compatible actions are the intersection |
| 4 | Prevent invalid mixed-object actions | LaunchBar | Unsafe operations are absent |
| 5 | Move multiple files and undo | Finder/Raycast | Atomic move restores every original path |
| 6 | Duplicate multiple files and undo | Raycast | Every generated copy is removed by one Undo |
| 7 | Compress multiple files and undo | LaunchBar | Every ZIP is tracked and reversible |
| 8 | Trash and restore | Spotlight/Finder | Exact original path is restored |
| 9 | Save an action chain as automation | Alfred Workflows | Recipe JSON preserves action, sources, and target |
| 10 | Narrow by result kind | Spotlight | Filtering happens before ranking |
| 11 | Compose path and extension filters | LaunchBar | Both qualifiers must match |
| 12 | Upgrade old clipboard data | Alfred/Raycast | Existing text history survives migration |
| 13 | Store image clipboard content | Spotlight/Raycast | Image data round-trips under the size cap |
| 14 | Store multiple file references | Alfred/LaunchBar | All paths round-trip in order |
| 15 | Complete first-run setup once | Raycast | Completion persists and prevents repeat presentation |
